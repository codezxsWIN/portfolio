#1 The question

Crawler and agent defences make strong claims that are hard to check. What would an honest, reproducible measurement look like?

#2 The approach

A fixed-origin gateway scores independent request and behaviour signals in off, shadow or live mode. Every decision leaves an evidence trail; suspicious clients can be led into a signed, expiring, finite decoy maze.

#3 The rule

Headers are evidence, not identity. A score of 90 from headers and rate alone still cannot authorize diversion.

What’s inside — and the safety property of each layer

            
          

          
    
            
  • L01
    Detector
    Scores independent request and behaviour signals.
    No diversion from weak header evidence alone.
    • 
            
  • L02
    Canary
    Adds a non-public link to eligible suspicious HTML.
    Never in shadow mode or below threshold.
    • 
            
  • L03
    Ticket signer
    Authenticates maze state with HMAC-SHA256.
    Forged and expired routes look like ordinary 404s.
    • 
            
  • L04
    Decoy corpus
    Serves deterministic, curated factual notes.
    No runtime generation, no misinformation.
    • 
            
  • L05
    Telemetry
    Records scores, actions and signal codes.
    No raw IP, body, cookie or full User-Agent.
    • 
            
  • L06
    Operator
    Shows real gateway state and pseudonymous events.
    Refuses non-loopback binding.
    • 
          

        


        

          
Defensive research only. It does not retaliate, exploit clients, poison training data, or make claims about crawler ownership. The maze concept is inspired by Cloudflare AI Labyrinth; CrawlerLab is independent and not affiliated.

Optional analyzer

            

              
Target source is data. Nothing is executed.

              
            

            
Point it at a local checkout or a public GitHub URL. Workflows, Terraform, hooks and dependencies are read, never run. Analysis has a 120-second deadline, supports cooperative cancellation and never publishes a partial result.

          

          
    
            
  • GitHub Actions
    Assessed Exact branch OIDC, finite matrices, literal env/matrix context.
    Not assessed Arbitrary expressions, secret values.
    • 
            
  • CloudFormation
    Assessed Literal IAM role trust, finite Secrets Manager reads, same-template policy attachments.
    Not assessed Intrinsic evaluation, full policy composition.
    • 
            
  • Terraform JSON
    Assessed Literal IAM role and inline policy declarations in one module file.
    Not assessed HCL, state or plans, provider execution.
